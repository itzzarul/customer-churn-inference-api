# Submission Notes

This repository package addresses the capstone requirements:
- FastAPI microservice with `POST /predict` accepting JSON and returning prediction probabilities.
- Dockerfile for containerization.
- Pinned dependency versions.
- Pytest unit tests for response schema and validation.
- README with setup, endpoints, request example, Docker commands, architecture, and limitations.
- Saved model artifact and reproducible training script.

Before submitting:
1. Run `pytest -q`.
2. Build and run the Docker image.
3. Push the project folder to a GitHub repository.
4. Copy the public repository URL (or the private repository URL if evaluator access is granted) into the course portal's "Submit deliverable" field.
5. Confirm that the dataset is permitted to be shared publicly. If not, remove the CSV from the public repository and explain its authorised source in the README.
